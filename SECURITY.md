# Política de Segurança — Iniciativa VIA

## Escopo

O `via-hub` é um **site estático**: HTML, CSS e JavaScript servidos pelo GitHub Pages. Não há back-end, banco de dados, autenticação nem coleta de dados pessoais. As ferramentas publicadas rodam inteiramente no navegador de quem as usa, e o estado eventual (progresso de trilhas, por exemplo) fica em `localStorage`, no próprio dispositivo.

Isso reduz a superfície de ataque, mas não a elimina. São relevantes para esta política:

- Falhas no código publicado (XSS, injeção de conteúdo, dependências comprometidas).
- Links maliciosos, conteúdo adulterado ou defacement de páginas.
- Uso indevido da identidade, da marca VIA ou da assinatura profissional do autor (CRM), inclusive páginas que se apresentem falsamente como oficiais.
- Exposição acidental de dados sensíveis em commits ou arquivos publicados.

## Como relatar

Prefira, nesta ordem:

1. **Issue pública** — para falhas sem risco imediato de exploração: <https://github.com/LucasHRAlmeida/via-hub/issues/new>
2. **Contato direto** — para qualquer coisa que não deva ser pública antes da correção: [WhatsApp Business +55 16 99618-0196](https://wa.me/5516996180196)

Ao relatar, ajuda muito incluir: a URL afetada, os passos para reproduzir, o navegador utilizado e o impacto que você observou.

## Compromisso de resposta

Esta é uma iniciativa independente, mantida por uma pessoa — não há plantão 24/7. O compromisso realista é:

- **Confirmação de recebimento**: em até 7 dias.
- **Avaliação e retorno**: em até 30 dias.
- **Correção**: priorizada conforme o impacto; falhas que exponham usuários ou comprometam a identidade profissional vêm primeiro.

Relatos feitos de boa-fé são bem-vindos e não serão objeto de retaliação. Pedimos apenas que a pesquisa não degrade o serviço para terceiros nem acesse dados que não sejam seus.

## Fora de escopo

- Ausência de cabeçalhos de segurança que o GitHub Pages não permite configurar.
- Resultados automatizados de scanners sem impacto demonstrável.
- Conteúdo hospedado em domínios de terceiros apenas referenciados por este site.

## Conteúdo de saúde

Se você identificar **erro clínico, informação desatualizada ou risco de dano** em qualquer conteúdo de saúde publicado aqui, trate isso com a mesma urgência de uma falha de segurança e use os canais acima. Correções de conteúdo médico são prioritárias.
