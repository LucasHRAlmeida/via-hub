# perguntas — banco de perguntas comuns em saúde

## Finalidade

Este diretório abriga o banco de perguntas frequentes em saúde, organizado por especialidade.

Cada especialidade possui um arquivo `ESCOPO.md` com:

- escopo educativo;
- perguntas típicas;
- fontes aplicáveis;
- status de verificação.

## Regras

- Nenhuma pergunta é respondida sem ficha individual com fonte verificada.
- Fonte pendente de verificação não é fonte elegível para citação.
- Material educativo não substitui diretriz clínica.
- Prioridade para fontes em português e contexto do SUS.
- Toda ficha cuja fonte foi verificada registra data de consulta, data de revalidação e próximo vencimento.

## Especialidades neste lote

- cardiologia
- diabetes-endocrinologia
- infectologia
- pediatria
- ginecologia-obstetricia
- pneumologia
- psiquiatria-saude-mental
